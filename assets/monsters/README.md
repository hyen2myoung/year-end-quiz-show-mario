# 원작 몬스터 모션

`original-sources.json`에 파일별 게임, 캐릭터, 원본 주소, 프레임 수, 재생 간격과 추출 방법을 기록했습니다.

- Mario Wiki에서 받은 GIF 26종 중 25종은 원본 파일을 그대로 사용합니다. GIF에 담긴 픽셀·프레임 순서·재생 간격을 변경하지 않았습니다.
- 마귀의 원본 GIF는 마법탄 이동 공간까지 포함해 폭이 넓으므로, 캐릭터·지팡이 영역만 잘라 손실 없는 WebP로 저장했습니다. 원본 GIF도 보존하며 프레임의 픽셀·순서·재생 간격을 유지합니다.
- DS판 패러굼바·초록/빨강 날개엉금엉금 3종은 Mario Universe의 원작 프레임 시트에서 셀을 잘라 손실 없는 애니메이션 WebP로 저장했습니다. 패러굼바 시트의 단색 배경만 투명하게 처리했습니다. 90ms 재생 간격은 원작 엔진에서 추출한 값이 아닌 근사값입니다.
- 킬러·초대 마리오의 버블은 기존 원본 스프라이트를 사용하며 위치를 이동합니다.
- DS판 쿠파주니어·쿠파·좀비쿠파는 검증된 원작 연속 프레임을 확보하지 못했습니다. 해당 슬롯은 기존 원본 정지 이미지를 사용하며, 다른 작품의 모션이나 임의의 이미지 변형으로 대체하지 않습니다.

CSS는 화면 안 이동 경로와 밟혔을 때의 납작해지는 표시·퇴장만 담당합니다. 몬스터 크기는 집중 모드의 구름이·노을이 몸 크기(약 80px)에 맞춥니다. 스타트 화면처럼 둘이 나란히 계속 달리고, 오른쪽에서 오는 적을 번갈아 연달아 밟습니다. 굼바를 포함해 밟힌 적은 즉시 퇴장하고 다음 적이 화면 밖에서 들어옵니다. 작은 별과 100 팻말은 장식이며 실제 점수는 올라가지 않습니다. 전투는 무음이고 사용자의 버튼 조작과 화면 전환 시 즉시 양보합니다. 타이머는 문제 창 아래 오른쪽에 고정합니다.

원작 이미지의 권리는 Nintendo에 있습니다. 개별 자료의 출처·설명은 JSON의 `filePage`와 `downloadUrl`에서 확인할 수 있습니다.
