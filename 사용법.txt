SW 센터 송년회 퀴즈쇼 (옛날 횡스크롤 게임 테마) 사용법

[실행]
"송년회 퀴즈쇼.html" 을 Chrome 또는 Edge 로 더블클릭하면 됩니다. 설치할 것은 없습니다.
첫 클릭 때 전체화면으로 바뀝니다. 폴더 구조는 그대로 두고 통째로 옮겨 주세요.

[진행 순서]
표지(게임 시작) → 파이프 판에서 파이프 고르기 → 쑥 내려가기 → 검은 입장 카드 → 스테이지(문제)
→ 선물 블록을 치면 정답 → 클리어 화면 → 들어갔던 파이프에서 쑥 올라와 깃발
48개 파이프가 한 화면에 다 보입니다. 분야마다 탑이 하나씩 나란히 서 있고(맨 위 간판에 분야 이름과 푼 개수),
탑마다 아래층 하 ★ · 가운데층 중 ★★ · 꼭대기층 상 ★★★ 에 문제 번호 파이프가 4개씩 있습니다.
층마다 발판 벽돌 색이 난이도 색이라 멀리서도 층이 구분됩니다 (하 초록, 중 노랑, 상 빨강 벽돌).
벽돌 색은 settings.js levels 의 color 로 바꿉니다 (green, gold, red, blue, purple).
푼 파이프는 회색이 되고 빨간 깃발이 붙습니다. 아래 막대의 동전 숫자가 푼 문제 수입니다. 모두 풀면 ALL CLEAR 가 나옵니다.

[게임 연출]
 · 표지 → 파이프 판: 네모 블록이 대각선으로 화면을 덮었다가 걷힙니다.
 · 파이프 판: 구름이가 파이프 위를 폴짝폴짝 건너가고 노을이가 바로 옆 파이프로 따라옵니다.
 · 파이프 → 문제: 구름이가 한 칸씩 뚝뚝 파이프 속으로 내려가고, 노을이가 따라 올라와 같이 내려감 → 바로 깜깜해지며 입장 카드
   → 스테이지 왼쪽 파이프에서 둘이 차례로 쑥 올라와 뛰어내립니다.
 · 문제 창은 게임 대화창처럼 가는 줄에서 옆으로, 다시 위아래로 펼쳐집니다.
 · 정답: 선물 블록을 치면 "정답 공개!" → 문제 창이 접히고 둘이 오른쪽으로 달려 나가며 화면이 흘러감 → 블록 전환 → 정답.
 · 집중 모드: 문제·정답 화면은 전환이 다 끝나면 배경이 어둡게 가라앉고 캐릭터·블록·버튼이 작아져 창만 또렷하게 남습니다.
   문제 창은 금빛 테두리로 한 번 반짝입니다. 시계는 크기 그대로입니다.
 · 벽돌 블록을 누르면 구름이가 머리로 쳐서 동전이 한 번 나옵니다 (+200점).
 · 표지에는 꼬마 펭귄이 걸어와서 캐릭터가 밟습니다.
 · 점프·착지 때 몸이 찌그러지고 눈먼지가 일며, 시간이 끝나면 화면이 흔들립니다.

[캐릭터 옷]
 구름이·노을이는 원래 목도리 색으로 앞 마크와 앞으로 튀어나온 챙이 있는 모자 + 금단추 멜빵바지를 입습니다.
 점프할 때는 주먹을 위로 번쩍 들고 뒷팔은 뒤로, 앞무릎은 접어 올립니다.
 예전 목도리 모습으로 돌리려면 settings.js 의 heroOutfit 을 false 로 바꾸세요. 모든 동작 모음: preview/outfit.html
 파이프를 드나들 때는 입구 아래로 들어간 몸이 잘려 보이지 않아서, 꼬리나 발이 파이프 밖으로 삐져나오지 않습니다.

[아래 막대 TIME]
 파이프 판: 표지에서 게임 시작을 누른 뒤 지난 총 진행 시간
 문제 화면: 문제 화면이 뜬 뒤 지난 시간 / 정답 화면: 그 문제에 걸린 시간 (정답을 연 순간에 멈춤)
 타이머 남은 초는 노을이가 든 시계에 나옵니다. 전체 초기화하면 총 진행 시간도 처음부터입니다.

[점수 (아래 막대 SCORE)]
 깃발(푼 파이프) 하나 1000점 · 정답을 열 때 남은 타이머 1초당 50점(TIME BONUS 로 세어 줌) · 벽돌 동전 200점 · 펭귄 100점
 점수는 재미로만 쓰는 것이고, 운영 패널의 전체 초기화 때 0 으로 돌아갑니다.

[문제 바꾸기]  data/questions.js
  "상식_중_1": {
    q: "문제 글자",          줄바꿈은 \n
    q_img: "사진파일.png",   문제 사진
    q_audio: "음악파일.mp3", 문제 음악
    a: "정답 글자",
    a_img: "정답사진.png",   정답 사진
    a_audio: "정답음악.mp3"  정답 음악
  },
사진과 음악은 resources 폴더에 넣고 파일 이름만 적습니다. 쓰지 않는 항목은 지워도 됩니다.
내용이 빈 칸은 파이프 판에서 어두운 회색 파이프로 보이고 눌리지 않습니다.
고친 뒤 화면이 안 나오면 쉼표(,)나 따옴표(")가 빠지지 않았는지 확인하세요.

[타이머]
문제 화면 아래쪽의 금빛 블록 5 / 10 / 15 를 누르면 그 시간으로 바로 시작합니다.
구름이가 달려가 블록을 머리로 치고, 노을이가 자명종을 머리 위로 번쩍 들어 남은 시간을 보여 줍니다.
시계는 시작할 때만 나타나고, 화면 위 TIME 에도 남은 초가 나옵니다. 마지막 5초는 빨갛게 흔들립니다.
도는 중에 다른 블록을 누르면 새 시간으로 처음부터 다시 시작합니다.
파란 II 블록을 누르면 멈추고, 초록 ▶ 로 바뀐 블록을 다시 누르면 남은 시간 그대로 이어서 갑니다 (Space 도 같음).
블록의 초는 data/settings.js 의 timerPresets, 긴박 연출 시작 초는 urgentSeconds 에서 바꿉니다.

[정답]
가운데 빨간 선물 블록을 누르거나 Enter(또는 오른쪽 아래 "정답 보기")를 누르면
구름이가 블록을 치고 선물이 튀어나온 뒤 정답 화면으로 넘어갑니다.

[분야, 난이도, 제목]  data/settings.js
 · categories 의 stage 로 분야별 스테이지 배경을 고릅니다.
   day = 한낮 눈 언덕, night = 별 뜬 밤 마을, sunset = 노을 언덕, ice = 얼음 동굴
 · color 는 파이프 색, 탑 간판, 문제 창 이름표 색입니다.
 · levels 는 탑의 층 순서(위에 적은 것이 아래층)와 그 층 벽돌 색입니다.
 · titleTop, titleMain, subtitle, eyebrow, year, credit 은 표지 글씨입니다.
 · snowAmount 는 눈송이 개수입니다. 행사 PC 가 느리면 50 정도로 낮추세요.

[진행 중 조작]
표지      Enter 게임 시작
파이프 판 ←→ 같은 층 옆 파이프(탑 끝에서는 옆 탑으로)   ↑↓ 같은 탑 위·아래 층   Enter 쑥 들어가기
          마우스: 파이프를 한 번 누르면 그 위로 이동, 같은 파이프를 한 번 더 누르면 들어갑니다
문제      1 / 2 / 3 타이머 5·10·15초 시작   Space 타이머 멈춤/이어서   Enter 정답 보기   Esc 지도로
정답      Enter 지도로
대화창    방향키로 고르고 Enter, 또는 1 / 2 / 3
언제나    O 운영 패널   F 전체화면
사진을 누르면 크게 볼 수 있습니다.

[새로고침 잠금]
F5, Ctrl+R, 뒤로 가기는 막혀 있습니다. 브라우저 버튼으로 새로고침하면 경고창이 뜨고,
그래도 새로고침했다면 보던 화면, 푼 문제, 타이머까지 그대로 돌아옵니다.
진행 기록은 이 PC 의 브라우저에 저장되므로, 다른 PC 나 다른 브라우저에서는 처음부터 시작합니다.

[리허설 후 초기화]
운영 패널(O) 오른쪽 아래 "2초 눌러 전체 초기화" 버튼을 길게 누릅니다. 행사 전에 꼭 한 번 눌러 주세요.
잘못 고른 문제는 문제 화면에서 Esc → "안 푼 문제로 되돌리기", 또는 운영 패널의 "되돌리기"로 되살립니다.

[배경음·효과음]
배경음: 표지는 Super Mario Bros 「Overworld Theme」, 문제 고르는 파이프 화면은 Super Mario Bros 3 「World Map 1·2·3·4·7」을 차례로 돌려 틉니다.
  문제·정답 화면에서는 꺼지고, 지도로 돌아오면 멈췄던 곳부터 이어집니다. 곡 파일은 assets/bgm 폴더, 곡 목록·음량은 settings.js 의 bgmTracks / bgmVolume.
  브라우저 정책상 첫 클릭(또는 키 입력) 뒤부터 소리가 납니다. 끄려면 settings.js 의 bgm: false.
효과음: 받아 둔 마리오 효과음을 원작에서 그 소리가 나는 동작에 붙였습니다 (assets/sfx 폴더, 앞뒤 빈 소리를 자르고 음량을 맞춤).
  점프 = Jump, 블록 치기·새로고침 막힘 = Bump, 동전 = Coin, 펭귄 밟기 = Stomp, 파이프 = Pipe,
  게임 시작 = 1UP, 정답 공개 = Item Block → PowerUp, 정답 화면 = Level Clear, 깃발 = FlagPole,
  모든 문제 끝 = Castle Clear + Fireworks, 시간 종료 = Lose a Life.
  타이머 5·10·15초는 P Switch 곡이 남은 시간에 맞춰 나오고, 멈추면 같이 멈췄다가 이어집니다.
  커서·메뉴·대화창·멈춤의 짧은 삑 소리는 코드로 만든 8비트 소리입니다.
  전체 표는 assets/sound.js 맨 위. 음량은 settings.js 의 sfxVolume, 끄려면 sound: false.

[디자인]
옛날 게임 플레이 화면을 참고해 이렇게 맞췄습니다.
 · 화면 맨 아래 검은 상태 막대: 월드·점수·동전·남은 시간 판, 가운데 조작 안내, 오른쪽에 구름이·노을이 칸.
 · 하늘은 한 가지 색, 언덕은 점무늬, 큰 물체에는 오른쪽·아래로 새까만 그림자.
 · 땅 위에 큰 선물 상자 발판, 표지에는 하늘에 떠 흘러오는 동전 줄(뛰어올라 먹음)과 펭귄.
 · 문제 창은 네 귀퉁이에 못이 박힌 큰 흰 블록, 정답 창은 연두 블록.
화면 전체를 가로 320 × 세로 180 칸짜리 옛날 게임기 화면으로 보고 한 칸을 6픽셀로 키워 그렸습니다.
배경, 블록, 캐릭터, 불꽃놀이가 모두 같은 크기의 네모 점으로 맞물립니다.
언덕·구름·전나무·눈사람·집·얼음 기둥이 겹겹이 다른 속도로 흘러가고, 눈이 계속 내립니다.
그림은 모두 코드로 찍은 것이라 따로 넣을 그림 파일이 없습니다 (assets/pixel.js, assets/world.js).
캐릭터 구름이·노을이는 도트 테마 때 확정한 그림(B 몸통 + 6번 얼굴, 점 하나 코)을 그대로 씁니다 (assets/hero.js).
글씨는 도트 글꼴 갈무리11 이며 assets/fonts 에 들어 있어(SIL OFL 1.1) 인터넷 없이도 그대로 보입니다.
특정 게임의 캐릭터, 로고, 그림, 음악은 쓰지 않았고, 옛날 횡스크롤 게임 분위기로 새로 만든 것입니다.
